# Introduction to SQL: Practice & Portfolio Projects

## 📌 Project Overview & Table Design
This repository documents hands-on database creation, relational modeling, and SQL query analysis completed using SQLite.

### Table Schema & Column Decisions
- **`customers`**: Stores user identity records.
  - `customer_id` (PRIMARY KEY): Unique integer identifier for each customer.
  - `customer_name` (TEXT): Name of the registered customer.
- **`subscriptions`**: Holds product and pricing tiers.
  - `subscription_id` (PRIMARY KEY): Unique integer identifier for each plan.
  - `description` (TEXT): Name of the subscription package.
  - `price_per_month` (NUMERIC/INTEGER): Monthly cost associated with the plan.
- **`orders`**: Junction table mapping customer orders to subscriptions.
  - `order_id` (PRIMARY KEY): Unique order identification.
  - `customer_id` (FOREIGN KEY): Links the order to a specific record in `customers`.
  - `subscription_id` (FOREIGN KEY): Links the order to a specific plan in `subscriptions`.

## 🛠️ Key Learning Objectives & Core Concepts Mastered

1. **Schema Definition (`CREATE TABLE`)**: Defining relational schemas with explicit column data types (`INTEGER`, `TEXT`, `REAL`) and constraints (`PRIMARY KEY`, `NOT NULL`, `FOREIGN KEY`).
2. **Data Manipulation (`INSERT`, `UPDATE`, `DELETE`)**: Populating data models with structured sample values and executing updates.
3. **Multi-Table Relational Joins**: Connecting data via `INNER JOIN`, `LEFT JOIN`, and `CROSS JOIN` across foreign key relationships.
4. **Common Table Expressions (`WITH` CTEs)**: Organizing complex query flows into modular temporary result sets.
5. **Data Aggregations & Grouping**: Calculating metrics using `SUM()`, `COUNT()`, `GROUP BY`, and differentiating row-level filters (`WHERE`) from aggregate filters (`HAVING`).

## 📊 Business Query Projects

### 1. Subscription Revenue Report
- **Goal:** Measure total monthly revenue generated by subscription plan.
- **Logic:** Merges `subscriptions` metadata with `orders` line items, applying `SUM(subscriptions.price_per_month)` grouped by plan description.

### 2. High-Value Repeat Customer Analysis
- **Goal:** Identify loyal buyers with multiple active orders.
- **Logic:** Joins `customers` and `orders` data, grouping by customer name and isolating accounts using `HAVING COUNT(orders.order_id) > 1`.
